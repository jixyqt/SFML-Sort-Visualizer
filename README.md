# SFML-Sort-Visualizer
This Sorting Algorithm Visualizer is a program that allows you to visualize various sorting algorithms in action. It provides a graphical representation of the sorting process, allowing you to observe how different algorithms manipulate and sort data.

Requirements
To run the Sorting Algorithm Visualizer, you need to have the following dependencies installed:

SFML library (version 2.5 or above)
C++ compiler compatible with SFML
Installation
Clone or download the repository to your local machine.
Install the SFML library by following the official SFML installation guide specific to your operating system.
Compile the code using your preferred C++ compiler, linking against the SFML library.
Run the compiled executable to launch the Sorting Algorithm Visualizer.
Usage
Upon launching the Sorting Algorithm Visualizer, you will be presented with a home screen that provides instructions for selecting different sorting algorithms. Use the following keys to choose a sorting algorithm:

Press 'A' for Bubble Sort
Press 'B' for Insertion Sort
Press 'C' for Selection Sort
Press 'D' for Merge Sort
Press 'E' for Quick Sort
After selecting a sorting algorithm, the visualization window will open, and the sorting process will begin. You can observe the sorting algorithm in action as it manipulates and rearranges the data.

The visualization window displays a set of rectangles, each representing an element in the data set. The height of each rectangle corresponds to the value of the element. The current element being processed by the sorting algorithm is highlighted in red.

Additional information, such as the current time and the number of iterations, is displayed at the top of the window.
